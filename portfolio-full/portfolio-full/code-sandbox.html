data contract

Schema assertions before anything gets modeled

Every incoming record is checked against a contract before it reaches the model: required fields present, traffic values non-negative, timestamps parseable. Records that fail are routed out and logged instead of silently corrupting a training or scoring run.

assert page["traffic_30d"] >= 0
assert page["last_crawled"] is not None
assert 0 <= page["decay_score"] <= 1
